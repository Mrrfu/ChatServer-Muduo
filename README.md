# ChatServer-Muduo
基于muduo网络库的C++聊天服务器，使用muduo构建服务器的基本功能。
    
## 环境

## 编译
    cd build

    cmake ..

    make
生成的可执行文件在bin目录下。

### 服务器端功能

软件设计按照分层设计，分为三层： 业务层、数据层、表现层。业务模块需要和数据操作模块分开，尽量解耦合。不能在业务层中出现对数据库操作的代码（增删查改）。
服务器基于muduo网络库作为网络模块，提供高并发的网络IO性能。为提高并发能力，还支持服务器集群部署。使用Nginx作为反向代理，接受客户端的请求并根据设置的分配算法转发至某台服务器。服务器处理后将消息发送至Nginx，再发送至客户端。

### 客户端功能

客户端支持单人实时聊天和多人实时聊天。具体功能有：添加好友，加入群组，创建群组。
客户端使用两个线程：读线程和写线程。读线程专门接受从服务器发送的数据，写线程用于将客户端数据发送至服务器。两个线程之间的通信用信号量进行（sem_t），注意只能在 Linux 使用（跨平台可以替换为 C++20 的信号量）。当创建 socket 成功后启动一个子线程作为读线程，接受用于处理后续的登录、注册、创建群组业务的返回信息以及聊天信息。


### 分布式部署
使用nginx作为tcp负载均衡器。服务器之间通信使用基于订阅-发布的redis消息队列。
